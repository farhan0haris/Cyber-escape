> MISSION OBJECTIVE

Cyber Escape is a tactical cybersecurity escape game. Trapped inside a locked mainframe terminal, you must successfully clear 5 consecutive security sectors before the countdown timer reaches zero to initiate emergency disconnect.

> FIVE SECTOR PROGRESSION

01
PASSWORD BREACH Forensic deduction

Analyze terminal access logs and deduce the root password hash from forensic clues.

02
DIGITAL MAZE Digital navigation

Navigate 2D memory grid channels to reach and unlock the security gateway.

03
MEMORY FORENSICS Memory investigation

Inspect cryptographic memory blocks and filter out corrupt decoys.

04
FIREWALL DODGE Real-time evasion

Evade sweeping laser barriers, packet hazards, and dynamic firewall surges.

05
SYSTEM OVERRIDE Final system operation

Recall sequence patterns, balance core frequencies, and initiate disconnect.
